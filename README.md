# Clínica Patas & Cia.

Sistema web de gerenciamento de tutores e animais para uma clínica veterinária.

## Objetivo

Desenvolver uma aplicação web que permita cadastrar, consultar, atualizar e excluir tutores e seus respectivos animais, mantendo o relacionamento entre os registros.

## Tecnologias

- HTML, CSS, JavaScript
- Node.js
- Express
- PostgreSQL
